# Gastrointestinal Disease Classification Using Deep Learning

## Project Overview
This project uses deep neural networks to classify gastrointestinal diseases from endoscopic images.

## Technologies Used
- Python
- TensorFlow/Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Medical image classification
- Deep learning model training
- Improved prediction accuracy using ensemble techniques
